# ParcelMate 上线手册（手机能打开）

> 目标：让学长用手机扫不到二维码也行，直接输一个网址就能打开你的系统。
> 全程约 30 分钟，其中 10 分钟是等服务器开机。

---

## 0. 先选一条路

| 方式 | 花费 | 手机能不能打开 | 适合场景 |
|---|---|---|---|
| **A. 学生云服务器**（本手册主推） | 约 10 元/月 | ✅ 任何网络都能开 | 面试要发链接、要给室友长期用 |
| B. 手机和电脑连同一个 WiFi | 0 元 | ✅ 仅同一 WiFi | 现场演示，学长和你在一起 |
| C. Render 免费档 | 0 元 | ✅ 但会休眠、数据会丢 | 备份方案，不推荐当面试链接 |

**B 的做法**（不花钱，先试这个）：电脑上跑着服务，查本机内网 IP（`ipconfig` 里 192.168.x.x），手机浏览器打开 `http://192.168.x.x:8080`。打不开就是 Windows 防火墙挡了 8080，放行即可。

下面写的是 **A 的完整步骤**。

---

## 1. 买机器（约 10 分钟，含学生认证）

1. 打开 [阿里云高校计划](https://university.aliyun.com/) 或 [腾讯云学生机](https://cloud.tencent.com/act/campus)，用学信网/校园邮箱做**学生认证**（几分钟审核）。
2. 选最低配就行：**2 核 2G、Ubuntu 24.04 LTS、40G 系统盘**。地域选离你近的（如重庆/成都/上海）。
3. 设置 root 密码（记下来），记下**公网 IP**（形如 `47.108.x.x`）。
4. 进控制台的**安全组 / 防火墙**，加一条入方向规则：**TCP 8080，源 0.0.0.0/0**。
   - 这一步不做，手机永远打不开——最常见的坑。

> 为什么用 8080 而不是 80：国内云服务器用 80 端口对外提供网站需要**备案**，8080 不需要。

---

## 2. 把 jar 传上去（约 5 分钟）

1. 下载 [WinSCP](https://winscp.net/)（免费），新建站点：
   - 主机名：你的公网 IP
   - 用户名：`root`
   - 密码：第 1 步设的密码
   - 协议：SFTP（默认）
2. 连上后，把本压缩包里的 **`parcelmate-0.1.0.jar`** 拖到右侧 `/root/` 目录。
3. 顺便把 **`parcelmate.service`**、**`seed_demo.py`** 也拖到 `/root/`。

---

## 3. 装 JDK 并启动（约 5 分钟）

用 SSH 登录服务器（Windows 自带命令，在 PowerShell 里敲）：

```bash
ssh root@你的公网IP
```

然后**逐行复制**执行：

```bash
# 装 Java 21
apt update && apt install -y openjdk-21-jre-headless

# 建目录、放文件
mkdir -p /opt/parcelmate/data
cp /root/parcelmate-0.1.0.jar /opt/parcelmate/app.jar
cp /root/parcelmate.service /etc/systemd/system/
cp /root/seed_demo.py /opt/parcelmate/seed_demo.py

# 开机自启 + 现在启动
systemctl daemon-reload
systemctl enable --now parcelmate

# 看状态（出现 active (running) 就成了）
systemctl status parcelmate --no-pager
```

> 想让服务一直活着、重启后自动起来，靠的就是 systemd 这三行。挂了会自动重启（`Restart=always`）。

---

## 4. 验证

1. 手机浏览器打开 **`http://你的公网IP:8080`** —— 应该看到 ParcelMate 首页。
2. 打不开就按顺序排查：
   - `systemctl status parcelmate` 是不是 running
   - 安全组有没有放行 8080
   - `tail -n 50 /opt/parcelmate/app.log` 看报错

---

## 5. 灌演示数据 / 重置 / 备份

**灌数据**（在服务器上执行，把 IP 换成你的）：

```bash
cd /opt/parcelmate
python3 seed_demo.py --base http://你的公网IP:8080
```

最后一行会打印房间码，比如 `{"code": "8SLPD5", ...}`。手机打开网址 → 输房间码 → 昵称随便填（建议填你自己的名字）→ 直接就能看到 2 张待接 + 1 张已接。

**清空数据重新来一遍**：

```bash
systemctl stop parcelmate
rm -rf /opt/parcelmate/data/*
systemctl start parcelmate
```

**每天自动备份数据库**（crontab 一行）：

```bash
crontab -e
# 粘这一行（每天 3 点备份，保留最近 7 天）
0 3 * * * cp /opt/parcelmate/data/parcelmate.db /opt/parcelmate/backup-$(date +\%F).db && find /opt/parcelmate -name 'backup-*.db' -mtime +7 -delete
```

**看日志 / 重启 / 停服**：

```bash
tail -f /opt/parcelmate/app.log     # 实时日志，Ctrl+C 退出
systemctl restart parcelmate         # 改了配置就重启
systemctl stop parcelmate            # 停
```

## 6. 常见报错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 手机一直转圈 / 打不开 | 安全组没放行 8080 | 云控制台加 TCP 8080 规则 |
| `Unit parcelmate.service not found` | service 文件没放对位置 | `ls /etc/systemd/system/parcelmate.service` 确认 |
| `Failed to start` + 日志里 `no main manifest` | jar 传坏了 | 重新用 WinSCP 传，比对文件大小约 34 MB |
| 日志里 `SQLITE_BUSY: database is locked` | 有别的进程占着 db | 只跑一个实例：`ps aux \| grep java` |
| 页面能开但没数据 | 还没灌数据 | 跑第 5 步的 seed 命令 |
| `Port 8080 was already in use` | 上一次的进程没死 | `pkill -f parcelmate && systemctl start parcelmate` |
| 手机打开是空白页 | 浏览器缓存 | 换无痕窗口 / 加 `?v=2` 再打开 |

## 7. 上传 GitHub（用 SSH，不依赖网页登录）

这台机器**走网页 HTTPS 连 GitHub 会被重置**（实测 `Recv failure: Connection was reset`），但 **SSH 22 端口是通的**（实测能建连，只是还没配公钥）。所以用 SSH 推。

**已经帮你生成了密钥**，公钥是这一串（复制完整一行）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIGRq+PbpZZOKc/VCMl0LOrAiBBZ/bnkwb90AER0Eaa+p pangjingyang-parcelmate
```

步骤：

1. 登录 GitHub → 右上角头像 → **Settings** → **SSH and GPG keys** → **New SSH key** → 标题随便写（如 `pang-laptop`），粘贴上面的公钥 → 保存。
2. 在 GitHub 上新建仓库，名字 `parcelmate`，**不要**勾选 README / .gitignore（本地已有），建完记下用户名。
3. 回到本机 PowerShell：

```powershell
cd "C:\Users\pang\Desktop\面试准备\parcelmate"
git remote add origin git@github.com:你的GitHub用户名/parcelmate.git
git push -u origin master
```

推完之后，README、截图、源码就都在 GitHub 上了。面试时可以直接把仓库链接发给学长。

## 8. 面试当天的三条命令

```powershell
# 本机演示（不用服务器）
java -jar target\parcelmate-0.1.0.jar

# 灌一份干净又有层次的演示数据
python scripts\seed_demo.py
```

- 首页地址：`http://127.0.0.1:8080`
- 演示数据房间码：以 seed 输出的 `code` 为准
- 手机演示：两台设备各开一个浏览器，分别加入两个昵称，才能演「A 发单 → B 接单 → A 收到红点」
